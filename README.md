# amzscout-skill-mcp
AMZScout Skill + MCP - bringing real Amazon research data into Claude, ChatGPT, Cursor, OpenClaw and other MCP clients

## Available Tools

Full documentation for every tool this MCP server exposes is available in [`/tools`](./tools).

| Tool | Description |
|------|--------------|
| `amzscout-agent` | All-in-one natural-language Amazon research assistant |
| `amzscout_analyze_product` | Full data for a single product by ASIN |
| `amzscout_compare_products` | Side-by-side comparison of 2–5 products |
| `amzscout_analyze_product_set` | Data + aggregates across 2–100 ASINs |
| `amzscout_analyze_niche` | Market snapshot for a niche/keyword |
| `amzscout_compare_niches` | Head-to-head comparison of niches |
| `amzscout_search_products` | Keyword search for products |
| `amzscout_find_by_brand` | List products under a brand |
| `amzscout_get_keywords` | SEO/PPC keyword data |
| `amzscout_recommend_tool` | Recommend the right tool for a use case |
| `amzscout_search_knowledge` | Search the AMZScout knowledge base |
| `amzscout_usage` | Check remaining token balance |

## Requirements

An AMZScout account with API/MCP access is required. See [learn.amzscout.net/amazon-product-api-for-ai-agents](https://learn.amzscout.net/amazon-product-api-for-ai-agents) for details.
