---
description: Show your AMZScout token balance (remaining / used / limit)
allowed-tools: [amzscout_usage]
---

Call the `amzscout_usage` tool and report the user's AMZScout token balance in one
short line: remaining, used, and limit (and note if it's a trial). Do not call any
other tool. If the tool returns an error, relay it plainly.
